# FinWise AI – Financial Literacy Platform

**Making financial literacy simple, practical, and accessible.**

FinWise AI is a web-based financial literacy platform designed to help students and young adults develop better money-management skills. It provides an interactive environment where users can learn about personal finance, understand their spending habits, create budgets, set savings goals, and explore important financial concepts.

The platform combines financial education with interactive tools and a chatbot that helps users understand money-related questions in simple, easy-to-follow language.

## Project Overview

Managing money can be challenging, especially for students and young adults who are still developing financial independence. Many people struggle with budgeting, saving, understanding debt, and making informed financial decisions.

FinWise aims to address this challenge by providing an accessible platform that makes financial concepts easier to understand through practical examples, interactive learning activities, and financial planning tools.

## Features

### 1. Financial Dashboard
- Overview of monthly income and expenses.
- Displays savings and remaining balance.
- Spending breakdown and financial health indicators.
- Financial tips and learning progress.

### 2. Budget Planner
- Record monthly income.
- Organise expenses into categories.
- Monitor spending against available income.
- Calculate remaining funds after expenses.

### 3. Savings Goals
- Create personal savings goals.
- Set target amounts.
- Track savings progress.
- Monitor progress towards financial targets.

### 4. FinWise AI Chatbot
An interactive financial literacy chatbot that allows users to ask questions about personal finance.

Topics include:
- Budgeting and money management.
- Saving strategies and emergency funds.
- Debt and loan management.
- Credit scores and credit management.
- Interest and compound interest.
- Basic investment concepts.
- Financial planning.

The chatbot supports typed questions and suggested prompts. Its conversation window supports scrolling, and its floating launcher is positioned at the bottom-right corner of the website.

### 5. Financial Quiz
- Interactive financial knowledge questions.
- Multiple-choice answers.
- Immediate feedback.
- Score tracking.
- Explanations to reinforce learning.

### 6. Financial Topic Library
Provides educational content covering:
- Budgeting.
- Saving.
- Expenses.
- Debt.
- Credit.
- Investing basics.
- Emergency funds.
- Financial goals.

## Getting Started

### Prerequisites

- A web browser (Chrome, Edge, Firefox, etc.).
- A code editor such as Visual Studio Code.
- Live Server extension (recommended).

### Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/FinWise.git
```

2. Navigate to the project folder:

```bash
cd FinWise
```

3. Open the project in Visual Studio Code.

4. Run `index.html` using Live Server or open it directly in your browser.
